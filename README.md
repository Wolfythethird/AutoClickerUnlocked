# AutoClickerUnlocked

A feature-rich, high-performance Python auto clicker with support for custom CPS rates, an uncapped speed mode, a clean dark-mode GUI, and command-line execution.

## Features

- **GUI & CLI Modes:** Launch a sleek GUI interface built with `customtkinter` or run directly in the terminal.
- **Customizable Speed:** Set target Clicks Per Second (CPS) ranging from 1 to 50.
- **Uncapped Speed Mode:** Remove CPS rate limits to run clicks as fast as possible while maintaining hotkey responsiveness.
- **Global Hotkey:** Press **F6** anywhere to instantly toggle clicking on or off.
